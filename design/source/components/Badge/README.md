# Badge

A short status or category label beside a title, in a table cell or on a card.

## Props
- `tone`: `'neutral'` (default) · `'accent'` · `'success'` · `'warning'` · `'danger'` · `'info'`.
- `dot`: a leading status dot. `icon`: a small leading icon. `children`: one or two words.

## Do / don't
- The word carries the meaning; colour only reinforces it ("Failed", not just a red dot).
- Sentence case, no punctuation. Don't use badges as buttons.
