# Avatar

A person's photo, or their initials on `accent-subtle` when no photo is set.

## Props
`name` (required: used for initials and the accessible label), `src` (photo URL), `size`: `'xs'` 24 · `'sm'` 32 · `'md'` 40 (default) · `'lg'` 56.

## Do / don't
- Use `md` in list rows, `sm` in dense tables and comments, `lg` on profile headers.
