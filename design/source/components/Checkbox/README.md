# Checkbox

An on/off choice that takes effect when a form is submitted, or one of several independent options in a list.

## Props
`label`, plus native checkbox props: `checked` / `defaultChecked`, `onChange`, `disabled`, `name`, `value`.

## Do / don't
- The whole label is the hit area; keep labels short and positive ("Email me about updates").
- For a setting that applies immediately, use Switch instead.
