# Icons

33 outline icons for web and mobile: 24×24 grid, 1.75px stroke, round caps and joins. The files are drawn in `#71717a` (`text-muted`, light) so they read on both themes in this gallery; when you inline them or import them into Xcode / Android Studio, set the stroke to `currentColor` (or template/tint rendering) and colour them with a text token. In React, use `TS.Icon` instead of the files.

- Navigation: `home`, `search`, `bell`, `user`, `settings`, `menu`, `grid`, `more`.
- Direction: `chevron-left`, `chevron-right`, `chevron-up`, `chevron-down`, `arrow-left`, `arrow-right`.
- Actions: `plus`, `close`, `check`, `edit`, `trash`, `filter`, `upload`, `download`, `logout`, `eye`, `heart`, `star`.
- Status: `info`, `alert`, `check-circle`, `x-circle` (used by Alert and Toast).
- Objects: `calendar`, `mail`, `lock`.
