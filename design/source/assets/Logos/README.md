# Logos

Placeholder identity, set in the platform system font; replace when a final logo exists.

- `ts-monogram.svg`: white "TS" on `accent-primary` (#7c3aed), 64px, radius 16. Favicons, avatars for the product, small spaces. Reads on both themes.
- `ts-wordmark-light.svg`: monogram + "TinySolution" in `text-primary` light (#18181b). Use on light grounds only.
- `ts-wordmark-dark.svg`: the same with the name in `text-primary` dark (#dcddde). Use on dark grounds only.
- `ts-app-icon.svg`: 1024×1024 square, unmasked, for the iOS App Store and Android adaptive icon foreground/background; the platforms apply the corner mask.
